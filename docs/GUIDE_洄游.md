# 洄游 · Anabasis —— 生成式三维粒子场的算法哲学

> 一件以「六万粒子、四态轮转、故障带」为主体的三维粒子作品。参考坐标：明日方舟终末地官网 `#lore` 区的粒子场（酸性黄 / 薄荷绿 / 品红三色、屏幕空间故障带、点精灵羽化辉光、由一张图到另一张图的粒子形变）。
> 本文件遵循 algorithmic-art 技能的要求：先立算法哲学，再落实现。

---

## 一、总纲：粒子不是画笔，粒子是流民

传统绘画先决定形状，再填充材质。这套算法反其道而行：**形状不是被画出来的，而是被六十万个游荡的点临时「认领」的聚居地**。
每个粒子在出生时就拿到四组坐标（鲸骨 / 棱镜环 / 归潮字 / 星壳）与四个随机数（相位、尺寸、层级、活性），它的一生就是在四组坐标之间反复迁徙。屏幕上看到的任何轮廓，都只是「此刻正在这里的那些点」投下的影子——
**画面不是物体的肖像，而是运动的横截面。**
这决定了作品的美学底线：任何一帧都必须能单独成立（可作为静帧出图），而任何一帧都不是终点（它必然正在离开或正在抵达）。

## 二、四态：四种空间意志

同一批粒子轮转四种聚居形态，形态之间不是「切换」而是「迁徙」，故取名 **Anabasis（远征 / 上行）**。

1. **鲸 · 骨架**——水平伸展的生物骨架，点的密度沿脊椎与鳍面分布，边缘薄、体内厚（z 轴 ±0.22 到 ±2.3）。它是「血肉」意志：有重心、有朝向、有呼吸的余地。
2. **棱镜环**——三只不同半径、不同倾角的光环绕同一根中轴缓慢相互切割。它是「机械」意志：几何、精确、拒绝叙事。
3. **归潮**——粒子散成两个字，随即又要散掉。它是「语言」意志：所有符号都是临时共识，写下即开始消解。
4. **星壳**——斐波那契球面上均匀分布的空心壳。它是「消散」意志：密度均质、不再有方向，最接近纯粹的场。

四态共同回答一个问题：**同一堆物质，能被组织成多少种「意义」？** 从生物到机械到语言到虚空，物质不变，只是权重的分配变了。

## 三、形变：尖度即张力

形变的数学核心只有一行：`spike = dot(w, w)`（权重向量的自点积）。

- 完全落定时权重为 `(1,0,0,0)`，`spike = 1`；
- 四态均混时权重为 `(0.25,0.25,0.25,0.25)`，`spike = 0.25`；
- 于是 `scatter = 1 - clamp((spike - 0.5)/0.5)` 就成了一个天然的「混乱度量」：**落定即 0，途中即 1。**

它被用来做一件事——把形变途中的粒子沿随机方向向外推开 1.0～4.0 个世界单位（云半径约 7、可见半高约 8.6，因此推开量必须"留在取景内"）。
于是形态之间不再是平滑的直线平移，而是**一次呼吸式的炸开与重新收拢**：旧形状先松开手，新形状再接住。
这条约束是本作第一原则的具体化：**自由必须留在画框里，否则不是自由，是消失。**

## 四、色彩：颜色是状态，不是物体

配色直接承自参考站的酸性色板：`#fffa00` 酸性黄（生物态）、`#00ffa2` 薄荷绿（机械态）、`#ff1aac` 品红（故障与消散）。
颜色由 `uC0..uC3` 与同一组权重混合，**所以颜色随形态迁徙而流过粒子**：粒子本身没有颜色，只有「此刻属于哪个形态」。
第三色品红不参与形态配色，而是被保留为**故障专色**——它只在故障带上出现，是这套系统里唯一的"外部信号"。

## 五、故障带：模拟媒介的自我怀疑

参考站最令人记住的不是形状，而是**横向撕裂的故障带**：按屏幕空间 y 坐标划出四条带，带内的粒子整体横向位移。
本作把它实现为 `glitchBand()`：每条带由 `(y0, x0, y1, x1)` 四元组定义，位移量 `uGlitchXOffset` 很小（0.55 世界单位），但足以让粒子云产生"信号错位"的错觉。
故障脉冲每 4.2 秒确定性触发一次，且**由种子计算**（`mulberry32(seed*7919 + i*104729)`），因此同一组种子必然得到同一串故障——**混沌可以复现，这才是生成艺术与随机噪声的区别**。
故障期间片元会向品红偏移并提亮，衰减速率与 `glitch` 参数成反比：故障不是事故，是可调的乐器。

## 六、技法：点精灵的雕琢

一粒粒子在屏幕上只有两三个像素，因此全部表现力都压在着色器里：

- **圆形羽化点精灵**：`gl_PointCoord` 距心超过 0.5 直接 `discard`，再用 `feather`（外围羽化）与 `core`（内核高光）两层 `smoothstep` 叠加出"光斑"而非"方块"。
- **深度淡出**：`distanceAlpha = 1 - clamp((viewZ - fadeStart)/(fadeDistance - fadeStart))`，让靠近相机的粒子更亮更大、远离的自动消隐——**透视不是几何，是亮度**。
- **层级差异**：`(-0.25 * aRnd.z + 1.25)` 让每个粒子落在 1.0–1.25 不等的亮度层上，避免整片云"平板一块"。
- **加性混合**：`AdditiveBlending` + 关闭深度写入，使粒子交叠处自然过曝成白心，得到与参考站一致的"磷光堆叠"质感。
- **点尺寸公式**：`size * pointScale / viewZ * (0.55 + 0.9*aRnd.y) + 常量 + 1.6`，并 clamp 到 [1, 64]——保证即使用户把粒子数拉到 16 万，也不会出现巨型方块糊屏。

## 七、交互：把相机交给观众

作品默认四面轮转、缓慢自转；观众可以用拖拽（带惯性）改方位、滚轮改距离、双击触发一次故障脉冲。
**「可旋转」是这件作品的定义性特征**——因为粒子的形状只有在绕行中才会暴露它的厚度：鲸是薄的骨架，环是空心的环，星壳是均匀的球壳。
出图模式（`?frames=N&bare=1&cam=az,pol,dist`）把时间与机位都钉死，因此**同一组参数、同一帧号，永远得到同一张图**。这是本作的第二原则：**作品必须可复现，否则它只是偶发事件。**
