# 归潮 · Tidal Condensation
### 一个算法艺术流派宣言 / An Algorithmic Philosophy

**归潮**认为：形状不是被画出来的，而是被**吸引过来的**。图像不是一个静态的结果，而是一次收敛——九千个彼此独立的粒子在噪声洋流里漂流、被看不见的引力牵引、最终在同一个轮廓上停下来。任何一帧都只是这场收敛的切片；真正的作品是那段过程，是"从散到聚"的那几百帧。

这一派的语法由三种力写成：**噪声场**给出集体漂移的意志（多层 Perlin 流场，尺度决定洋流的宽窄），**归巢力**给出个体记起自己位置的能力（弹簧式回拉，阻尼决定它是颤抖地归位还是果断地落定），**脉冲节律**给出呼吸（周期性的径向推力把已聚拢的粒子再度掀开，让形状在瓦解与重聚之间来回）。三力之比就是这一派的全部乐理——哪一边多一分，画面就从"温柔的落尘"变成"风暴里的星群"。

颜色的语法是**状态的颜色**，不是物体的颜色。粒子不因为"它属于鲸的背部"而上色，而因为"它此刻离自己的位置有多远"而上色：漂移中的粒子是冷青的磷光，落定的粒子烧成暖金。于是观者看到的不是一只被涂色的鲸，而是**收敛度本身的热力图**——形状从颜色的温差里浮出来。这是把不可见的物理量直接当作颜料使用，是本流派最核心的技法。

关于**随机**：随机只被允许出现在两个地方——出发时每一颗粒子的位置，和它所认领的那一个目标点。其余一切必须由方程决定，且必须由同一个种子完全复现。同一颗种子永远是同一只鲸、同一片洋流、同一次呼吸。这是本派的纪律：**受控的混沌，可复现的奇迹**。任何一个参数都不是随手给的数字，而是被反复校准过的比率；调参不是设置，是作曲。

**技法要求**：本派不接受"随机撒点看起来还行"的作品。引力常数、阻尼、噪声尺度、脉冲周期与粒子密度的关系必须经过成百上千次实验才能定下来——每一个数值的背后都应当是一次次的观感比对与收敛速度的实测。线的宽度、透明度随收敛度的渐变曲线，尾迹衰减与画面暗噪的平衡，都必须像是出自此领域最顶尖的匠人之手：**精雕细刻的算法，反复优化的产物，深湛计算美学功底的结果**。粗糙的实现一眼可辨——粒子抖动、轮廓糊成一团、颜色断层、尾迹脏成一片；而这些，本派一概不认。

**变奏空间**：种子是作品的另一维。同一套方程，换一颗种子就换一只生物、换一次洋流的性格。作品因此不是一张图，而是一族由图组成的物种——每一个种子是一份标本，收藏者收集的是"这一只"与"那一只"之间那点无法言说的差异。

*（本作的隐性典故：默认种子 52052，脉冲周期取自 52 赫兹——那头发出的歌声没有任何同类能听见的鲸。它依旧按自己的频率呼吸、聚拢、再散开。识者自识。）*
